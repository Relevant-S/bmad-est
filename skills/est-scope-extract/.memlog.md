- (decision) Skill est-scope-extract: skill #1 of the BMad Delivery Estimator module (code est). Built from the completed plan at skills/reports/estimation-module-plan.md, section '### est-scope-extract'.
- (decision) Feature Inventory source of truth is feature-inventory.json; .md and .csv are rendered projections produced on demand by scripts/render-inventory.py. Chosen over markdown-as-source because verbatim citations carry pipes, newlines and non-English text that markdown tables mangle, and est-estimate needs clean structured input.
- (decision) Intent modes create / update / validate. The plan's 'scope diff' capability is realised as update mode (re-extract against an existing inventory, emit diff, merge) rather than a bolt-on capability. validate is a read-only recheck of an inventory against its sources before it feeds an estimate.
- (decision) Working state: the Feature Inventory IS the structured working artifact. Plus a memlog for human classification overrides, because update mode must never silently clobber a human tag correction with a fresh machine inference.
- (decision) Every tag carries status inferred|confirmed|overridden in the schema. This is the mechanism that protects human corrections across re-extraction; the memlog carries the reasoning behind an override.
- (decision) No customize.toml. User declined; skill ships fixed with hardcoded paths and no resolver step.
- (decision) Parsing dependencies installed globally by module setup (user choice). Scripts additionally declare them in PEP 723 so uv run self-heals on a machine that skipped setup, and degrade gracefully to pdftotext/openpyxl/native reading when neither is available.
- (decision) Four scripts: convert-input.py (sources to normalized markdown + manifest), inventory-check.py (schema validation + input completeness score + coverage stats), render-inventory.py (JSON to md/csv), inventory-diff.py (two inventories to a scope diff). All deterministic, all unit-testable.
- (note) Non-negotiable carried from the plan: two-way traceability. Every feature cites file + location + verbatim quote (original-language quote preserved); every part of the source not treated as scope appears in not_scope with a reason. Silent invention and silent omission are the failure modes that kill the module.
- (note) The input completeness score is computed by script from model-set signals, not chosen by the model, because it later determines estimate band width in est-estimate. The formula must stay inspectable.
- (gap) Seed cost-model.md does not exist yet (est-estimate builds it). Classification vocabulary is therefore carried in references/classification-guide.md for now, and must be reconciled with _bmad/memory/est/cost-model.md when est-estimate is built.
- (decision) Dropped markitdown in favour of direct libraries (python-docx, openpyxl, pypdf, python-pptx) plus the pdftotext CLI. Direct libraries give better structural fidelity, which is what makes citable location anchors possible: page markers for PDFs, sheet names and row numbers for workbooks, heading levels for documents. markitdown flattens those away, and without anchors a citation cannot name a verifiable location.

- (event) Analyze lens finding determinism-1 (critical) confirmed by reproduction and fixed. convert-input.py was renumbering rows after filtering blanks and promoting row 1 to a header, so a workbook with a title banner cited 'Login' as row 3 when it sat at row 4, and the drift grew with every blank row above.
